# BR Car Rentals Management System

A Django-based vehicle rental web application with user and admin modules.

## Features

- User Registration & Login
- Vehicle Booking
- Booking History
- Bill Generation
- Contact Form
- Admin Dashboard
- Manage Cars
- Manage Users
- Manage Bookings
- Contact Messages

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript

## Run Project

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
